# Отчёт по топосъёмке: определение высот

**Проект:** topo-survey-report  
**Дата формирования:** 27.10.2026  
**Исполнитель:** Петросян Элен

## 1. Исходные данные

В папку `data` загружены следующие материалы:
- `points.csv` — каталог высот (координаты X, Y и отметки H).
- `topo_plan.dxf` — цифровой план участка.

## 2. Методика определения высот

Высоты определены на основании полевых измерений (тахеометрическая съёмка). Интерполяция отметок выполнена линейным методом.

## 3. Результаты обработки

На основании загруженных данных получены следующие характеристики рельефа:
- Минимальная отметка: 120.5 м.
- Максимальная отметка: 135.2 м.
- Перепад высот: 14.7 м.

## 4. Выводы

Рельеф участка характеризуется умеренным уклоном в юго‑восточном направлении. Данные пригодны для проектирования вертикальной планировки.
